# Competitive Programming Lab

Solutions to Competitive Programming Lab problems implemented in C.

## About

This repository contains solutions to problems assigned in the Competitive Programming Lab. Each solution focuses on problem-solving techniques, algorithms, and fundamental data structures.

## Topics Covered

* Searching and Sorting
* Arrays and Strings
* Bit Manipulation
* Stack and Queue
* Greedy Algorithms
* Graph Algorithms
* Dynamic Programming

## Language Used

* C

## Purpose

* Practise competitive programming problems.
* Improve algorithmic thinking and problem-solving skills.
* Understand data structures and algorithms.
* Maintain a collection of lab solutions for future reference.
